# Day 08 · 实现 KV 块分配与回收

连续增长的序列很难预留一整块刚好够用的显存。把逻辑序列分成定长块后，两个请求还能共享一段只读前缀。

**实验起点**　CPU 上做 Python 分配器，用 4 个物理块、每块 4 token 的小例子手算。

## 动手要求

1. 实现分配、追加 token、查询逻辑到物理块表、释放请求。明确未填满的尾块怎样处理。
2. 给共享块维护引用计数；两个请求共享未满尾块时，追加前执行 copy-on-write。测试淘汰只作用于可回收块。
3. 构造块数不足的请求，检查分配失败后的空闲列表和已有映射；逐次释放共享者，核对总块数守恒。

## 当天验收

- [ ] 提交块管理器与覆盖重复分配、尾块、共享写入、释放、淘汰和 OOM 的测试。
- [ ] 给出操作前后的映射图与计数；解释逻辑相邻为何可以映射到分散的物理块。
