# Day 10 · 用真实 token 测量前缀缓存

两个问题看起来相似，开头实际送入模型的 token 却可能不同。今天构造缓存一定能复用、部分能复用和完全不能复用的请求。

**实验起点**　沿用 Day 07 的请求格式、固定 tokenizer/revision 和一台 vLLM GPU 服务。

## 动手要求

1. 构造 0%、25%、50%、75%、90% 五档共享前缀；对应用 chat template 后的 token ID 计算最长公共前缀，保存脱敏 prompt 或可复建输入。
2. 保持输入和输出长度、到达率、采样及并发一致。将前缀缓存开关与冷/热状态分开；每轮注明重启、预填充与正式测量的顺序。
3. 将 TTFT 与服务端命中统计对照，标出块粒度和计数口径。把这批数据保留给 Day 28。
